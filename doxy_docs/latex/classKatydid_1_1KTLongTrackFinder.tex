\doxysubsection{Detailed Description}
Collects points from sparse spectrogram into linear tracks. 

\doxylink{classKatydid_1_1KTLongTrackFinder}{KTLong\+Track\+Finder} is designed to identify long-\/duration, variable-\/slope tracks in the sparse spectrogram data. It operates on sequential KTDiscriminated\+Point1\+DData objects emitted by the discriminator. These are single time slices containing over-\/threshold points. Configuration name\+: "{}long-\/track-\/finder"{}\hypertarget{classKatydid_1_1KTLongTrackFinder_config}{}\doxysubsection{\texorpdfstring{Available configuration values\+:}{Available configuration values\+:}}\label{classKatydid_1_1KTLongTrackFinder_config}

\begin{DoxyItemize}
\item "{}min-\/frequency"{}\+: minimum allowed frequency (has to be set)
\item "{}max-\/frequency"{}\+: max allowed frequency (has to be set)
\item "{}min-\/bin"{}\+: can be set instead of min frequency
\item "{}max-\/bin"{}\+: can be set instead of max frequency
\item "{}frequency-\/acceptance"{}\+: maximum allowed frequency distance of point to an extrapolated line (in Hz)
\item "{}time-\/gap-\/tolerance"{}\+: max time gap before track is deemed over.
\item "{}initial-\/frequency-\/acceptance"{}\+: if the line that a point is being compared to, only has a single point so far, this is the accepted frequency acceptance. Default is frequency\+\_\+acceptance
\item "{}initial-\/time-\/acceptance"{}\+: if the line that a point is being compared to, only has a single point so far, this is the accepted time window. Default is time-\/gap-\/tolerance
\item "{}initial-\/slope"{}\+: if a line has only one point, this is the line\textquotesingle{}s slope
\item "{}rel-\/slope-\/diff-\/to-\/expand"{} If the relative difference between the local slopes at the previous two time slices was greater than this, double the frequency acceptance. To recover from adding noise or to follow resonance.
\item "{}n-\/slope-\/slices"{}\+: maximum number of TIME SLICES to include in the slope calculation
\item "{}min-\/points"{}\+: a line only gets converted to a track if it has collected more than this many number of points
\item "{}max-\/points"{}\+: lines will be terminated after this many points. Good for curved tracks/resonances.
\item "{}min-\/slope"{}\+: a line only gets converted to a track if its slope is \texorpdfstring{$>$}{>} than this slope (in Hz/s)
